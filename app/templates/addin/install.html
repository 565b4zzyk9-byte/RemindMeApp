Outlook add-in

Install the RemindMeApp add-in to add a reminder straight from an open email in Outlook, without switching to the browser.

Manifest URL

{{ manifest_url }}

Outlook on the web

  1. Open an email, then in the ribbon choose Get add-ins (or the "..." menu → Get add-ins).
  2. Choose My add-ins → Add a custom add-in → Add from URL.
  3. Paste the manifest URL above and confirm.

Outlook desktop (new Outlook / classic)

  1. Go to Home → Get Add-ins → My add-ins.
  2. Choose Add a custom add-in → Add from URL and paste the manifest URL above.

An admin can also push this to everyone at once via the Microsoft 365 admin center (Settings → Integrated apps → Upload custom app), which avoids each person sideloading it individually.
